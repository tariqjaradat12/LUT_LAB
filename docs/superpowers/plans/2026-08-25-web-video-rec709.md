# Web Video Rec.709 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users open a video, grade it live with the existing WebGL tools/LUTs as display-referred Rec.709, and export a graded file at native resolution (no downscale), with a hard 15-minute export cap.

**Architecture:** Extend the edit store with a video element + object URL; each animation frame uploads the current `HTMLVideoElement` frame into `GradeRenderer`. Export seeks to 0, sizes an offscreen/native canvas to source W×H, grades frames while `MediaRecorder` records `canvas.captureStream()` (audio best-effort). Photos keep the existing ImageBitmap path.

**Tech Stack:** Vite, React 19, TypeScript, WebGL1 grader, HTMLVideoElement, CanvasCaptureMediaStream, MediaRecorder.

**Spec:** `docs/superpowers/specs/2026-08-25-web-video-rec709-design.md`

## Global Constraints

- Local-only; no uploads/accounts
- Color mode this phase: **Rec.709 only** (no log decode)
- Resolution: **native width × height; no downscale**
- Export duration hard cap: **15 minutes** (`900` seconds); preview may allow longer
- Prefer WebM; MP4 only if `MediaRecorder.isTypeSupported`
- Do not redesign LUTs Looks or unrelated tool tabs
- Frequent commits; do not push unless the user asks

```ts
export const MAX_EXPORT_DURATION_SEC = 15 * 60;

export function canExportDuration(durationSec: number): boolean {
  if (!Number.isFinite(durationSec) || durationSec <= 0) return false;
  return durationSec <= MAX_EXPORT_DURATION_SEC + 0.05;
}

export function formatTimecode(seconds: number): string {
  const s = Math.max(0, Math.floor(seconds || 0));
  const m = Math.floor(s / 60);
  const r = s % 60;
  return `${m}:${r.toString().padStart(2, '0')}`;
}

export function pickRecorderMimeType(): string | null {
  if (typeof MediaRecorder === 'undefined') return null;
  const candidates = [
    'video/webm;codecs=vp9,opus',
    'video/webm;codecs=vp8,opus',
    'video/webm',
    'video/mp4',
  ];
  for (const t of candidates) {
    if (MediaRecorder.isTypeSupported(t)) return t;
  }
  return null;
}

export function revokeVideoUrl(url: string | null | undefined) {
  if (url) URL.revokeObjectURL(url);
}

export async function loadVideoFromFile(file: File): Promise<{
  video: HTMLVideoElement;
  objectUrl: string;
  width: number;
  height: number;
  duration: number;
}> {
  if (!file.type.startsWith('video/') && !/\.(mp4|webm|mov|m4v)$/i.test(file.name)) {
    throw new Error('Please choose a video file (MP4, WebM, or MOV).');
  }
  const objectUrl = URL.createObjectURL(file);
  const video = document.createElement('video');
  video.src = objectUrl;
  video.playsInline = true;
  video.preload = 'auto';
  video.muted = true;
  video.crossOrigin = 'anonymous';

  await new Promise<void>((resolve, reject) => {
    const onErr = () => reject(new Error('Could not open that video in this browser.'));
    video.addEventListener('error', onErr, { once: true });
    video.addEventListener('loadedmetadata', () => resolve(), { once: true });
  });

  const width = video.videoWidth;
  const height = video.videoHeight;
  const duration = video.duration;
  if (!width || !height) {
    revokeVideoUrl(objectUrl);
    throw new Error('That video has no usable picture track.');
  }
  return { video, objectUrl, width, height, duration };
}
```

- [ ] **Step 1: Implement `setVideoFrame`**

```ts
setVideoFrame(video: HTMLVideoElement) {
  if (!this.tex) this.tex = this.gl.createTexture();
  const gl = this.gl;
  gl.activeTexture(gl.TEXTURE0);
  gl.bindTexture(gl.TEXTURE_2D, this.tex);
  gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, 0);
  gl.pixelStorei(gl.UNPACK_PREMULTIPLY_ALPHA_WEBGL, 0);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, video);
  this.imageSize = { w: video.videoWidth || this.imageSize.w, h: video.videoHeight || this.imageSize.h };
}
```

Do **not** change export to downscale. Photo `exportToCanvas(maxEdge)` may keep a still maxEdge; video export must never pass a shrink.
